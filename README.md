# sasquatch

Sasquatch is a patched version of unsquashfs used by Binwalk to extract non-standard or vendor-customized SquashFS filesystems from embedded device firmware.

### Builds ###

Download the latest [release](https://github.com/z0mb13w4r/sasquatch/releases).

### How to install ###

```bash
curl -O https://github.com/z0mb13w4r/sasquatch/releases/download/4.3/sasquatch
chmod +x sasquatch
sudo mv sasquatch /usr/bin/
```
